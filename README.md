# Testable_MultiLang_Proof_Suite

Minimal buildable proof repo demonstrating tool/version support across 5 languages. Real content lives on
the language branches, not here — `main` exists only as a diff/comparison baseline and repo landing page.

- `python` — minimal buildable Python package
- `java` — minimal buildable Maven project
- `csharp` — minimal buildable .NET project
- `javascript` — minimal buildable Node.js project
- `typescript` — minimal buildable TypeScript project

Each branch has its own `quality/<tool>/` fixtures proving real tool support within its supported version
range, per the Testable tool matrix.
